# 🚗 Car Wash Management & Loyalty System

A web-based management application developed for car wash businesses to streamline vehicle tracking, service management, payment records, and customer loyalty programs.

The system allows businesses to register incoming vehicles by license plate, record performed services, track transaction history, and automatically manage customer rewards.

### ✨ Key Features

- 🚘 **Vehicle Registration:** Register and track vehicles using their license plate numbers.
- 🧽 **Service Management:** Create and manage customizable car wash services with individual prices.
- 💰 **Price Tracking:** Define service prices such as exterior wash, interior cleaning, and full detailing.
- 📋 **Transaction History:** Keep detailed records of which services were performed, when they were performed, and their costs.
- 🎁 **Loyalty & Reward System:** Automatically track completed washes and offer a free wash after every 10 paid washes.
- 📊 **Business Management:** Maintain organized vehicle, service, and transaction records.
- ⚡ **Dynamic Interface:** Interactive user experience with AJAX-based operations without unnecessary page reloads.

### 🛠️ Technologies Used

- PHP
- HTML5
- CSS3
- JavaScript
- AJAX
- MySQL / Database Management

### 🎯 Project Goal

The main goal of this project is to digitize daily car wash operations, reduce manual record-keeping, simplify transaction tracking, and improve customer retention through an automated loyalty program.

Developed as a practical web application for managing real-world car wash business operations.
